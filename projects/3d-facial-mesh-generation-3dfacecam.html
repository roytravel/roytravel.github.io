Ellexi · Jul 2023 – Feb 2024 · 8 months

Overview

A third-party organization built a Korean face 3D mesh dataset covering 2,500 subjects, each with 51 expression variations (127,500 meshes in total), for public release on AI-HUB. Ellexi's role was to validate whether that dataset was actually usable: build a model that generates 3D facial meshes from emotional context, and certify it through an official reproducibility audit by the Telecommunications Technology Association (TTA), Korea's national ICT testing and certification body.

The validation model takes a Korean sentence describing a social situation, classifies the implied emotion with BERT, and generates the matching 3D facial mesh using 3DFaceCAM, a two-stage architecture that combines a Stacked Autoencoder for identity/expression disentanglement with a cGAN for mesh and texture synthesis. A key constraint: the dataset had been built with camera calibration rather than laser scanning, which meant vertex correspondence across subjects was not guaranteed. To work around this, the model had to be trained per subject. I wrote the R&D proposal that won the project, ran training on 4× A100 80GB GPUs to handle the scale, and built the Docker evaluation pipeline used for official TTA certification, hitting Diversity ≥ 1.3 and Specificity ≤ 0.90.

Diversity — how varied the generated meshes are
diversity = 2⁄n(n−1)m ∑i=1n−1 ∑j=i+1n ∑k=1m ‖xi(k) − xj(k)‖2
n = number of generated meshes · m = vertices per mesh · xi, xj = generated meshes i and j · xi(k) = k-th vertex of mesh i

Averages the vertex-wise distance between every pair of generated meshes. Higher means the model produces a wider range of shapes instead of collapsing toward one generic face.

Specificity — how closely meshes match a real face
x̄ = 1⁄n ∑i=1n xi,  specificity = 1⁄nm ∑j=1n ∑k=1m ‖x̄(k) − xj(k)‖2
x̄ = mean mesh across the training dataset · xj = generated mesh j · n = number of meshes · m = vertices per mesh

Averages the vertex-wise distance between each generated mesh and the training set's mean face. Lower means outputs stay anatomically realistic instead of drifting into distorted geometry.

Takeaways

Camera-calibration meshes break vertex correspondence, which breaks GAN training
The dataset was built by another company using camera calibration rather than laser scanning. Camera-calibration meshes don't share vertex topology across subjects, so there's no consistent correspondence for the model to learn from. The only workaround was training a separate model per subject — 2,500 subjects, 51 expressions each. Laser-scanned meshes solve this by construction.
GAN loss curves don't tell you if training is working
Generator and discriminator losses can look stable while the model is producing garbage. The only way to know is to inspect intermediate outputs throughout training.
Read open-source code critically — even from large organizations
Meta's published implementation had logic errors. Assuming that widely-cited code is correct is a fast way to lose weeks of debugging time.
Papers rarely release everything — plan to implement the gaps yourself
Key components are often missing from public repositories. Treat any research implementation as incomplete until you've verified each piece exists and works.
