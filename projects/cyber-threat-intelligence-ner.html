NLP / Security · Korea University · with Samsung SDS

Cyber Threat Intelligence NER

Korea University · Oct 2020 – Dec 2021

Overview

Security analysts drown in unstructured threat reporting. This project, done with Samsung SDS, aimed to extract structured threat entities automatically from that flood of text using named entity recognition.

I built 30+ crawlers to pull 50,000+ security articles, constructed a BIO-tagged domain-specific dictionary from scratch, and fine-tuned a PyTorch BERT-NER model — pushing F1 from 65% to 90% after a round of cleaning up mislabeled training data.
