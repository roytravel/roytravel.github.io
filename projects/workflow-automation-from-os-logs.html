Workflow Automation from OS Logs

Ellexi · Feb 2023 – Jan 2025 · with IITP

Overview

This IITP-funded national grant project set out to build a multi-modal model that watches a user's OS logs and recommends — then auto-executes — their likely next action. I wrote the technical proposal that won the funding.

Beyond modeling, the work included reverse-engineering Hancom office software to find bypass solutions where the automation needed to interact with software that had no public API, and presenting results as Project Manager at the National Tech Exchange.
