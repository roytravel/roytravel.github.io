Text-Prompted Rotoscoping Plugin

Ellexi · May – Jul 2023 · with MediaCan

Overview

Rotoscoping — manually tracing an object frame by frame — is one of the most labor-intensive tasks in video post-production. For client MediaCan, I built a FastSAM-based FastAPI server and packaged it as a plugin for Nuke, the industry-standard compositing software.

The plugin turns a plain text prompt into a Bézier-curve rotoscoping mask automatically, cutting out the manual frame-by-frame tracing entirely for the objects it targets.
