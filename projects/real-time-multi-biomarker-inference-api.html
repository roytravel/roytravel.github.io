Real-Time Multi-Biomarker Inference API

Synergy AI · 2025 – Present

Overview

A model is only useful once someone else's system can call it. I served the ECG-based blood-biomarker screening model as a real-time API so the backend team could integrate it directly into the product — no notebook hand-offs, no manual batch runs.

The API outputs per-biomarker abnormality probabilities across 33 biomarkers in a single call, running on FastAPI, ONNX, Triton, and Docker, with MLFlow logging the full pipeline end to end so every prediction is traceable back to the model version that produced it.
